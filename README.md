# Excuse Generator

A fun Python script that generates random excuses for why you can't go to work (or any other commitment).

## Usage

Run the script:

```bash
python main.py
```

Output example:
```
Sorry, I can't go to work today.
My cat is holding my car keys hostage
```

## Excuses

The project includes 21 unique excuses covering various themes:
- Pet-related excuses
- Health/medical jokes
- Technical difficulties (humorous)
- Productivity issues
- Absurd/funny scenarios

## Adding More Excuses

Add new excuses to the `excuses_list` in `main.py`:

```python
excuses_list = [
    "Your new excuse here",
    # ... existing excuses
]
```
